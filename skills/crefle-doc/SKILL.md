# CREFLE 문서 작성 (crefle-doc)

**템플릿을 복사해 내용만 채운다.** 스타일 가이드를 읽고 조립하지 않는다.

## 왜 이 규칙인가

이 DS 는 Claude 가 만든 덱 하나가 계기로 생겼다. 그 덱은 `<deck-stage>` 를 선언만 하고
JS 를 안 불러서 **PDF 가 49슬라이드 → 1페이지로 깨졌고**, `--primary` 를 `#A81E24` 로
자체 발명했고(파운데이션은 `#C9252C`), CDN 폰트를 써서 무네트워크 렌더러에서 폴백했고,
`style="color:#F3B0B5"` 를 19곳에 뿌렸다.

유능한 모델이 백지에서 시작해 전부 잘못 재발명한 것이다. **템플릿을 복사하면 그 실패가
구조적으로 불가능하다.**

## 절차

1. **템플릿을 고른다** — `templates/` 에서 복사한다.

   | 요청 | 템플릿 | 특징 |
   |---|---|---|
   | 보고서 · 제안서 · 기획서 | `report.html` | 표지 · 요약 먼저 · 개정이력 · 각주 |
   | 연구노트 · 실험 기록 | `research-note.html` | 시간순 · 가설/방법/결과/결론 · **실패도 기록** · 미해결 칸 |
   | 회의록 | `minutes.html` | 짧게 · **액션 아이템이 맨 위** · 표지 없음 |
   | 발표 · 덱 | `deck.html` | 1920×1080 슬라이드 · PDF 는 슬라이드당 1페이지 |

2. **번들을 문서 옆에 복사한다** — `dist/crefle-doc/` 를 통째로.
   ```
   내문서.html
   crefle-doc/          ← 이게 없으면 스타일도 폰트도 안 온다
   ```

3. **내용을 채운다.** 템플릿 주석이 각 자리에서 무엇을 쓸지 알려준다.

4. **확인한다** — 브라우저로 열어 본다. 등록 요청이 이어지면 `register-report` 로 넘긴다.

## 네 가지 금지

이것만 지키면 나머지는 템플릿이 해결한다.

1. **색을 쓰지 않는다.** `#`으로 시작하는 값도, `rgb()` 도. 토큰만 — `var(--primary)`.
   브랜드 레드는 `#C9252C` 이고 **파운데이션이 소유한다**. 문서가 정하지 않는다.

2. **`style="…"` 에 색·크기를 넣지 않는다.** 클래스를 쓰거나, 필요 없으면 안 쓴다.
   참조 덱이 브랜드에서 이탈한 경로가 정확히 이것이다.

3. **네트워크 자산을 추가하지 않는다.** `<link href="https://…">`, `@import url(https://…)`,
   CDN 폰트 전부 금지. 업로드 PDF 렌더러는 `network_mode:"none"` 격리 컨테이너라
   **100% 실패**한다. 필요한 폰트는 이미 번들에 있다(Spoqa · JetBrains Mono · Material Symbols).

4. **`<script src>` 를 지우지 않는다.** 덱의 `deck-stage.js`, 차트의 `crefle-chart.js`.
   덱에서 이걸 빼면 PDF 가 **1페이지로 깨진다**(실측: MediaBox 가 1440×810pt → 612×792pt US Letter).

## 클래스를 붙이려 하지 말 것

가장 흔한 실수다. **시맨틱 HTML 이 그냥 맞는다.**

```html
<h2>배경</h2>          <!-- 24px 장 제목. 클래스 불필요 -->
<h3>현황</h3>          <!-- 20px 절 제목 -->
<p>본문입니다.</p>      <!-- 16px 본문 -->
<table>…</table>       <!-- 표 스타일 자동 -->
<blockquote>…</blockquote>
<pre><code>…</code></pre>
```

실측: 예제 문서 1부의 46개 요소 중 클래스는 **3개**뿐이고 전부 `num`(수치 열)이다 —
HTML 에 "이 칸은 숫자다"를 표현할 방법이 없어서다.

클래스는 **HTML 에 대응 엘리먼트가 없는 것**에만: `.eyebrow` `.lede` `.kpi` `.callout`
`.capsule` `.label-pill` `.card*`. 자세한 건 `references/authoring.md`.

## 더 필요할 때

- **컴포넌트 목록과 사용법** → `references/authoring.md`
- **차트** (원형·막대·꺾은선) → `references/charts.md` — 원형은 조각 4개까지 등 제약이 있다
- **막힐 때** → `docs/known-issues.md`

## 없는 컴포넌트가 필요하면

만들어 쓰지 말고 **먼저 묻는다**. 한 번 쓰는 것이면 그 문서 안에서 끝내고(단, 색은 토큰),
세 곳에서 필요해지면 DS 에 넣을 후보다. 참조 덱의 radial·pattern·tree 다이어그램은
각 1~2회만 쓰여 DS 에 넣지 않았다.
