# 차트

`<crefle-chart>` — 원형 · 막대 · 꺾은선. `crefle-chart.js` 를 로드해야 합니다.

## 기본

```html
<crefle-chart type="bar" title="난이도별 품질 개선" caption="출처: Hwang (2026)" unit="점">
  {"series":[{"name":"품질 점수","data":[
    {"label":"Basic","value":23.8},
    {"label":"Expert","value":36.2}]}]}
</crefle-chart>
```

JSON 이 **인라인**인 것은 스타일 선택이 아닙니다. 문서는 `file://` 로 열리고, 그건
opaque origin 이라 `fetch()` 가 차단됩니다. 유일하게 작동하는 방법입니다.

| 속성 | |
|---|---|
| `type` | `bar`(기본) · `line` · `pie` |
| `title` | figcaption 이자 aria-label 의 앞부분 |
| `caption` | 출처 등. 차트 아래 작은 글씨 |
| `unit` | 값에 붙습니다(`23.8점`). **눈금은 맨 숫자** — 단위를 반복하지 않습니다 |
| `stacked` | 막대 누적 |
| `width` `height` | viewBox 논리 크기. 기본 640×320. 폭은 컨테이너에 맞춰 늘어납니다 |

원형은 `series` 대신 `data` 를 받습니다:

```html
<crefle-chart type="pie" title="구성" unit="%">
  {"data":[{"label":"A","value":98.4},{"label":"B","value":1.6}]}
</crefle-chart>
```

## 지켜야 할 제약 — 전부 계산으로 나온 것

### 원형은 조각 **4개까지**

원형은 모든 조각이 나란히 비교되므로 **all-pairs** 라는 더 어려운 색맹 안전성 검사를
받습니다. 그걸 통과한 건 앞 4슬롯뿐입니다. 5개 이상이면 컴포넌트가 콘솔에 경고합니다.

작은 항목은 **"기타"로 접으세요.** 색을 늘리는 게 아닙니다.

### 시리즈는 **8개까지**, 색은 순환하지 않는다

9번째를 요청하면 컴포넌트가 **던집니다**. 순환하면 9번째가 1번째와 같은 색이 되어
정체성 채널이 거짓말을 합니다. "기타"로 접거나 facet(작은 배수)으로 쪼갭니다.

### 차트는 **light 슬라이드/문서에만**

팔레트는 light 표면에서만 검증됐습니다 — 다크에선 8색 중 4개가 lightness band 를
벗어납니다. `.slide.dark` 위에 놓으면 콘솔에 경고합니다.

### 색을 직접 지정하지 않는다

슬롯이 순서대로 붙습니다. 굳이 바꿔야 하면 `series[].color` 가 있지만, **쓰지 마세요** —
검증된 팔레트를 벗어납니다.

## 왜 이 팔레트인가

```
1 브랜드레드 #C9252C   2 블루   3 옐로   4 바이올렛
5 그린                6 마젠타  7 아쿠아  8 오렌지
```

**단일 시리즈 차트는 모든 막대가 slot-1(브랜드 레드)** 입니다 — 보고서 차트 대부분이
단일 시리즈이므로 그게 CREFLE 차트의 기본 인상입니다.

이전 팔레트(primary 레드 + 차콜 사다리)는 검증에서 **3개 FAIL** 했습니다. 그중 하나는
"정상 시력으로도 구분 불가"(ΔE 13.3 < 15)인 hard FAIL 이었습니다. 단색 사다리는
**sequential(크기)** 구조인데 **categorical(정체성)** 에 쓴 것이 원인이었습니다.

green 이 5번인 이유: green ↔ 브랜드레드가 ΔE **2.7**(적록색맹)로 원형에서 충돌합니다.

**팔레트를 바꾸려면 눈으로 판단하지 말고 validator 를 돌리세요.** 명령은
`scripts/check-chart-palette.mjs` 의 실패 메시지에 그대로 나옵니다.

## 색만으로 구분하지 않는다 — 자동으로 제공되는 것

세 가지 의무가 있고 컴포넌트가 전부 갚습니다. 지우지 마세요:

- **범례** — 시리즈 2개 이상이면 항상. 단일 시리즈는 제목이 이름을 대신하므로 없음.
- **직접 라벨** — 단일 시리즈 막대의 값. 원형은 범례에 값·비율.
- **마크 간 2px 간격** — 인접 채움의 경계.
- **시각적 숨김 표** — 스크린리더용. `display:none` 이 아니라 클립입니다.
- **`role="img"` + 자동 aria-label** — 데이터에서 요약을 만듭니다.

왜 필요한가: 팔레트의 slot 3·6·7 은 표면 대비가 3:1 미만이고(값이 다른 방법으로 읽혀야 함),
**보고서는 흑백으로 인쇄됩니다** — 레드↔블루 상대명도차가 0.049 라 흑백에선 거의 같은
회색입니다. 색만 믿으면 인쇄본에서 정보가 사라집니다.

## 안 되는 것

- **이중 축**(y축 두 개) — 차트 만들기의 가장 흔한 실수입니다. 척도가 다른 두 측정은
  차트 두 개로 나누거나 공통 기준으로 지수화합니다.
- **막대 색으로 값 인코딩** — 막대 길이가 이미 값을 보여줍니다. 색은 정체성 채널이므로
  거기 쓰면 낭비입니다. 이름이 다른 항목들은 전부 같은 slot-1 색입니다.
- **모든 점에 숫자 붙이기** — 직접 라벨은 선택적으로.
