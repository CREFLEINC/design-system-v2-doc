차트

JSON 은 인라인이다. 문서는 file:// 로 열리고, 그건 opaque origin 이라 fetch() 가 차단된다 — 스타일 선택이 아니라 유일하게 작동하는 방법이다.

막대 — 단일 시리즈

모든 막대가 slot-1(브랜드 레드)이다. 단일 시리즈이므로 범례가 없다 — 제목이 이름을 대신한다. 직접 라벨이 값을 나른다.

{"series":[{"name":"품질 점수 개선","data":[ {"label":"Basic","value":23.8}, {"label":"Advanced","value":29.6}, {"label":"Expert","value":36.2}]}]}

막대 — 다중 시리즈

시리즈 2개 이상이면 범례가 항상 나온다. 정체성이 색만으로 전달되면 CVD·흑백 인쇄에서 사라진다. 막대 사이 2px 표면 간격으로 경계가 남는다.

{"series":[ {"name":"적용 전","data":[{"label":"정확도","value":49.5},{"label":"일관성","value":42},{"label":"재현성","value":38}]}, {"name":"적용 후","data":[{"label":"정확도","value":79.3},{"label":"일관성","value":78},{"label":"재현성","value":70}]}]}

꺾은선

2px 선, 마커에 2px 표면 링 — 점이 포개져도 경계가 남는다.

{"series":[ {"name":"하네스 적용","data":[{"label":"W1","value":52},{"label":"W2","value":61},{"label":"W3","value":70},{"label":"W4","value":79}]}, {"name":"기준선","data":[{"label":"W1","value":49},{"label":"W2","value":50},{"label":"W3","value":48},{"label":"W4","value":51}]}]}

원형

조각은 4개까지다. 원형은 모든 조각이 나란히 비교되므로 all-pairs 라는 더 어려운 CVD 검사를 받고, 그걸 통과한 건 앞 4슬롯뿐이다. 값과 비율은 범례에 직접 쓴다 — 조각 안에 넣으면 작은 조각에서 넘친다.

{"data":[ {"label":"하네스 (권한·컨텍스트·샌드박스·라우터·복구)","value":98.4}, {"label":"AI 의사결정 로직","value":1.6}]}
